# Trustworthy Local Document Intelligence — Stage 1

A local, fully-offline system on an Apple M1 (8GB unified memory) that:
- (a) answers questions over 15+ long documents containing numeric tables, and
- (b) verifies factual claims against those documents.

Numbers are never generated by the LLM — every numeric answer is computed in Python/pandas
against structured table data, with a citation back to `{doc, page, table_id, cell}`.

Status: **Phase 0 complete.** This README will be finalized in Phase 6 with full setup,
reproduction commands, and a repo map.

See `stage1_build_prompt_FINAL.md` for the full build spec and `AI_LOG.md` for a running log
of what the assistant did each phase.

## Environment (Phase 0)

- Hardware: MacBook Air, Apple M1, 8GB unified memory.
- Python: 3.11.5 via a dedicated conda env, since the system default `python3` is 3.7 (too old
  for `mlx-lm`). Create it with:
  ```
  conda create -n doc-intel python=3.11
  conda activate doc-intel
  pip install -r requirements.txt
  ```
- Verify Metal is visible to MLX: `python -c "import mlx.core as mx; print(mx.default_device())"`
  → expect `Device(gpu, 0)`.
- Offline proof: see `results/phase0_offline_proof.md`. Warm-state baseline on this machine is
  **~9 tok/s** at INT4, peak MLX memory **4.41 GB**.
